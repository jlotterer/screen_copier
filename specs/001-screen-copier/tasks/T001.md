# T001: Project skeleton, tooling, CI, empty window

## Goal
When this task is done, the repository is a working `src/`-layout Python package managed with uv: `pyproject.toml` declares the locked stack, the `screen-copier` GUI script, ruff and pytest configuration; every subpackage of the module layout exists as an empty `__init__.py`; `src/screen_copier/app.py` exposes `main()` that answers `--version` or opens an empty `QMainWindow` titled "Screen Copier"; and a Windows CI workflow runs lint and tests on Python 3.12 and 3.13. Every later task builds on this skeleton and only adds files.

## Acceptance criteria
- Given a fresh clone, When `uv sync` and then `uv run pytest` run, Then both succeed and `tests/test_smoke.py` is collected and passes.
- Given the package, When `screen_copier.app` is imported in a test, Then the import succeeds.
- Given `pyproject.toml`, When the `[project.gui-scripts]` table is read, Then it contains the entry `screen-copier = "screen_copier.app:main"`.
- Given the app module, When `main(["--version"])` is called, Then it prints `0.1.0` and returns exit code 0.
- Given pytest-qt with `QT_QPA_PLATFORM=offscreen`, When the main window is created, Then a `QMainWindow` with the title "Screen Copier" exists and can be shown.
- Given the repository, When `uv run ruff check .` and `uv run ruff format --check .` run, Then both pass.
- Given `.github/workflows/ci.yml`, When it is parsed as YAML, Then it defines a job on `windows-latest` with a matrix over Python 3.12 and 3.13 that runs `uv sync`, the lint commands and `uv run pytest` with `QT_QPA_PLATFORM=offscreen`.

## Notes for the worker
`pyproject.toml` carries project metadata with version `0.1.0`, the runtime dependencies with the version bounds from AGENTS.md (Python `>=3.12,<3.14`, PySide6 `>=6.8,<7`, opencv-python `>=4.10,<5`, numpy `>=2`, anthropic `>=0.70`, pydantic `>=2.7,<3`, keyring `>=25`, platformdirs `>=4`, PyYAML `>=6`), the dev dependencies pytest, pytest-qt and ruff, ruff configured for line length 100, and pytest configured with `testpaths = ["tests"]`, `qt_api = "pyside6"` and a registered `perf` marker ("timing test; skip on slow CI with -m 'not perf'"). Create every subpackage of the module layout in [architecture.md §3](../../../docs/architecture.md#3-module-layout) as an empty `__init__.py` so later tasks never edit a shared `__init__`. `main()` parses `--version` (print the version from package metadata, exit 0); otherwise it creates the `QApplication` and shows the empty main window. The `.gitignore` covers Python, uv and IDE files. Packaging rules are in [architecture.md §15](../../../docs/architecture.md#15-cli--packaging) and decisions [0001](../../../docs/decisions/0001-pyside6-desktop-app.md) and [0005](../../../docs/decisions/0005-windows-only-uv-tool-install.md).
