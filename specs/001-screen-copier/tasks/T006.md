# T006: Screen detection, warp, resize/encode

## Goal
When this task is done, `src/screen_copier/preprocess/` turns a full camera frame into a straightened, cropped, size-capped JPEG of just the source screen: `detect.py` finds the screen quad and smooths it for display, `warp.py` corrects perspective, caps the size and encodes, and `process()` ties them together honouring a locked quad. T014 runs `process` in a worker; T015 draws the quad.

## Acceptance criteria
- Given a synthetic screen rendered with a 15° perspective skew, When `detect_screen` and `warp_to_rect` run, Then a quad is detected, the warped image's aspect ratio is within 5% of the true screen's, and a rendered vertical line is straight within 2 px.
- Given a uniform gray image, When `detect_screen` runs, Then it returns `None`; When `process` runs on it, Then the full frame is used and `quad_used` is `None`.
- Given a locked quad and a frame where detection would find a different quad, When `process(frame, locked_quad, max_edge)` runs, Then the locked quad is the one used.
- Given a 3000×2000 image and `max_edge = 1568`, When `resize_cap` runs, Then the result is 1568×1045; Given an 800×600 image, Then it is returned unchanged.
- Given a synthetic 3840×2160 frame, When `process` runs 5 times, Then the median duration is ≤300 ms; the test is marked `@pytest.mark.perf`.
- Given the modules under `src/screen_copier/preprocess/`, When their import statements are inspected, Then none imports PySide6.

## Notes for the worker
Detection: grayscale → Gaussian blur 5×5 → Canny (50, 150) → dilate 3×3 → external contours → `approxPolyDP` at 2% of the perimeter → keep convex 4-point polygons with area ≥ 20% of the frame → take the largest and order corners TL, TR, BR, BL; `None` when nothing qualifies. `QuadSmoother` averages the last 5 detections for display only and clears its history on a miss so a stale outline disappears. Warp: estimate the aspect ratio from the quad with Zhang & He's whiteboard method (square pixels, principal point at the frame center); recover the focal length from the quad when both edge pairs converge and the estimate lies within 0.3–3.0 × frame width, otherwise assume 0.8 × frame width. Output size starts at width = max(top, bottom edge), height = max(left, right edge), then the shorter side grows to match the estimated ratio (never shrink); `getPerspectiveTransform` + `warpPerspective` with `INTER_CUBIC`. A degenerate result (non-convex quad, or quad or output area < 1% of the frame) falls back to the full frame with a logged warning. Resize with `INTER_AREA` so the long edge is ≤ `max_edge`, never upscale; encode color JPEG at quality 90, and these exact bytes are what gets stored and sent. `make_synthetic.py` renders code text onto a white rectangle, places it on a dark background with a 0–15° skew and adds Gaussian noise, deterministic from a seed.
