# T003: Hand-built FrameResult sequences + expected outputs (executable spec)

## Goal
When this task is done, `tests/fixtures/stitching/` holds twelve fixture folders, each a sequence of simulated Claude transcriptions (`frames/<seq>.json`) for a window scrolled over a hand-written `source.txt`, plus the exact document the stitcher must produce (`expected.txt`) and `meta.json` with the expected events, conflicts and flags. The fixtures exist before the stitcher does; T008 and T009 are "make these pass". This is the most important spec artifact in the project, so correctness matters more than speed and the owner reviews it before merge.

## Acceptance criteria
- Given the fixture root, When the folders are listed, Then exactly these twelve exist: `seq_basic`, `seq_partial_lines`, `seq_no_overlap`, `seq_bridge`, `seq_ambiguous_braces`, `seq_scroll_back`, `seq_conflicts`, `seq_linenums_gap`, `seq_linenums_start_missing`, `seq_soft_wrap`, `seq_mixed_numbering`, `seq_discard`, each with `source.txt`, `frames/`, `expected.txt` and `meta.json`.
- Given every `frames/<seq>.json`, When `tests/fixtures/test_fixture_schema.py` checks it with the standard `json` module only (no import of `screen_copier.models`, since T002 runs in parallel), Then every file has the ReportTool keys with the right types, and every line has all six line keys.
- Given a fixture whose `meta.json` lists no events and no conflicts, When `expected.txt` is compared with `source.txt`, Then they are byte-identical, and a test asserts this for every such fixture.
- Given `tests/fixtures/stitching/README.md`, When it is read, Then it describes the folder format, every `meta.json` key and every one of the twelve fixtures by name.
- Given `tests/fixtures/stitching/make_frames.py`, When it is run, Then the committed frame JSON, `expected.txt` and `meta.json` files are reproduced byte for byte, and a test asserts this.

## Notes for the worker
`source.txt` is realistic code of 40–150 lines, mostly Python, with one JSON file and one with many `}` lines. Frame JSON follows the ReportTool schema and simulates what Claude returns for a window onto the source, with `partial: true` and garbled text on clipped top and bottom lines where noted. `expected.txt` is the exact `render()` output with gap markers (Stitcher contract), LF line endings pinned by `.gitattributes`, spaces only. `meta.json` holds `description`, `uses_line_numbers`, `expected_events`, `expected_conflicts`, `expected_flags`, and for `seq_discard` also `discard: [2]`, `expected_after_discard` and `expected_events_after_discard`. What each fixture exercises: `seq_basic` 5 unnumbered frames with 2–4 lines of overlap, no issues; `seq_partial_lines` clipped edge lines must not leak into the output (REQ-STI-02); `seq_no_overlap` frame 3 jumps ahead → gap marker plus `gap_detected` (REQ-STI-06); `seq_bridge` the same plus a frame 4 that bridges the gap → `gap_closed` (REQ-STI-07); `seq_ambiguous_braces` a frame of only `});` and blank lines that fits two places → `ambiguous_overlap` (REQ-STI-06); `seq_scroll_back` down, back up (a contained frame), down again, no duplicates (REQ-STI-05); `seq_conflicts` uncertain-vs-certain, majority, and an unresolved conflict (REQ-STI-08); `seq_linenums_gap` numbered frames covering 1–40 and 48–90 → `lines 41–47 missing` (REQ-STI-03, -04); `seq_linenums_start_missing` first numbered frame starts at 5 → `lines 1–4 missing` at the top (REQ-STI-04); `seq_soft_wrap` a numbered frame with an unnumbered continuation line → `soft_wrap` flag and `word_wrap` event (REQ-STI-09); `seq_mixed_numbering` numbered frames plus one with the gutter cropped, placed by overlap; `seq_discard` frame 2 is junk (REQ-STI-10). Write `make_frames.py` as a declarative generator (window ranges, clipped flags, injected misreadings) and commit its output so the fixtures are reproducible. The algorithm the fixtures pin is in [architecture.md §9](../../../docs/architecture.md#9-stitching) and [§11](../../../docs/architecture.md#11-gap-marker--text-format); the reasoning is in [decision 0003](../../../docs/decisions/0003-stitch-text-not-images.md). Flag the PR for the owner: these fixtures define correct behavior, so a person must review them before merge.
