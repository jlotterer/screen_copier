# T005: Quality metrics + auto-capture state machine

## Goal
When this task is done, `src/screen_copier/camera/quality.py` computes the frame-difference and sharpness metrics on numpy arrays, and `camera/trigger.py` holds the pure `CaptureTrigger` state machine that decides when Auto mode captures a frame, with an injected clock and thresholds from `TriggerConfig`. T012's `CameraWorker` runs both per preview frame.

## Acceptance criteria
- Given a sharp synthetic text image and a Gaussian-blurred copy of it, When `sharpness` is computed for both, Then the sharp image scores higher.
- Given two identical frames, When `diff` is computed, Then the result is 0.
- Given a synthetic text image and a horizontally shifted copy, When `diff` is computed, Then the result is greater than the default `motion_threshold` of 6.0.
- Given a fake clock and default thresholds, When 10 frames with `diff_prev = 10` are followed by frames with `diff_prev = 0.5` and `sharpness = 200` spanning 700 ms, Then exactly one decision has `capture = True`.
- Given the state after that capture, When more frames with `diff_prev = 0.5` and `sharpness = 200` arrive, Then no further decision has `capture = True`.
- Given the state after that capture, When frames with `diff_prev = 10` arrive and then stable sharp frames for 700 ms, Then exactly one more capture is emitted.
- Given stable frames (`diff_prev = 0.5`) with `sharpness = 50` for 2 s, When updated, Then no capture is emitted and the state is `WAITING_FOCUS`.
- Given stable sharp frames with `diff_last_capture = 0.5`, When the settle time passes, Then no capture is emitted (duplicate of the previous capture, REQ-CAM-07) and the state is `CAPTURED`.
- Given 5 s of frames with `diff_prev = 10` and `sharpness = 200`, When updated, Then the decision's `hints` contains `never_settles`.
- Given the transition table in the CaptureTrigger contract, When the tests are read, Then every row has at least one test exercising its condition and outcome.
- Given `camera/quality.py` and `camera/trigger.py`, When their import statements are inspected, Then neither imports PySide6.

## Notes for the worker
`quality.py`: `prep` (grayscale, width 320, `INTER_AREA`), `diff`, `sharpness` and `is_blurry`, all on numpy arrays. `trigger.py`: `TriggerConfig` dataclass with `from_settings(settings)` reading the Settings keys by name, `TriggerDecision(state, capture, hints)`, and `CaptureTrigger(config, clock)` with `update(diff_prev, sharpness, diff_last_capture)`, `reset()` and `notify_manual_capture()`. Implement the transition table in the CaptureTrigger contract exactly, including the hysteresis in `CAPTURED` and the `never_settles` hint with its restart and clear rules. The clock is a callable returning seconds; never read real time. Build synthetic text images with OpenCV in the tests.
