# T016: Thumbnails, badges, context menu

## Goal
When this task is done, `src/screen_copier/ui/frame_strip.py` shows the captured frames as thumbnails in capture order with a status badge each, lets the user enlarge, discard, retry or re-recognize a frame, and emits `frame_selected(seq)` for the review view. It is fed by the controller's `frame_added` and `frame_updated` signals and acts through its slots. T019 docks it at the bottom of the main window.

## Acceptance criteria
- Given a `FrameStrip` bound to a stub controller, When the stub emits `frame_added` for three frames with statuses `queued`, `recognized` and `failed`, Then the strip shows 3 items in seq order with the badges "Queued", "Recognized" and "Failed", each badge having an icon as well as a color.
- Given the three frames, When the context menu is opened on the `failed` frame, Then it contains "Retry"; When it is opened on the `recognized` frame, Then it does not contain "Retry" but does contain "Discard" and "Recognize again".
- Given a selected frame with seq 2, When the Delete key is pressed on the strip, Then `controller.discard_frame(2)` is called once.
- Given a frame, When it is double-clicked, Then a full-size viewer dialog showing that frame's image opens.
- Given the stub emits `frame_updated` for a frame changing from `queued` to `recognizing`, Then its badge shows a spinner state; from `recognizing` to `discarded`, Then the item is dimmed.
- Given a frame whose `quality.blurry` is true, When it is shown, Then its badge also shows "Blurry".
- Given a frame is clicked, When the selection changes, Then `frame_selected(seq)` is emitted with that frame's seq.
- Given "Retry" is chosen on a failed frame and "Recognize again" on a recognized one, Then `controller.retry_frame(seq)` and `controller.rerecognize_frame(seq)` are called respectively.

## Notes for the worker
Build `FrameStrip(controller, session_dir)` as a horizontal `QListView` in icon mode backed by a `QAbstractListModel` fed from `frame_added` and `frame_updated` (match items by `Frame.seq`). Thumbnails are loaded from the frame's `image_file` under the session folder, off the GUI thread or lazily, since image decoding must not block. Badges: queued, recognizing (spinner), recognized, failed, discarded (dimmed), blurry, each with an icon shape and a color (REQ-NFR-08). The context menu offers Discard, Retry (failed only) and Recognize again, calling `discard_frame`, `retry_frame` and `rerecognize_frame`. Double-click opens a `QDialog` with the full-size image. Emit `frame_selected(seq)` on selection change. Tests use pytest-qt with a stub controller and small generated JPEGs in `tmp_path`. T015, T017 and T018 run in parallel in other `ui/` files; touch only the two files listed here. Background: [architecture.md §14](../../../docs/architecture.md#14-ui-structure).
