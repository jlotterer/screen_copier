# T020: Desktop shortcut, icon, README

## Goal
When this task is done, `screen-copier --create-shortcut` creates a "Screen Copier" desktop shortcut with the app icon through PowerShell, reports where it put it and exits non-zero on failure; `src/screen_copier/assets/icon.ico` ships as package data; and `README.md` documents what the app is, how to install it, how to set up the API key, how to capture well and how to troubleshoot.

## Acceptance criteria
- Given `subprocess.run` mocked to succeed, When `create_shortcut()` runs, Then the PowerShell script passed to it references `Screen Copier.lnk`, the resolved `screen-copier` executable path and the icon path, the shortcut path is printed, and the return value is 0.
- Given `subprocess.run` mocked to fail with stderr text, When `create_shortcut()` runs, Then the return value is 1 and the error text is printed to stderr.
- Given `main(["--create-shortcut"])`, When it runs with `create_shortcut` mocked, Then `create_shortcut` is called once and its return value is the exit code.
- Given `README.md`, When a test reads it, Then it contains the headings "Install", "API key", "Capture tips", "Troubleshooting" and "Privacy".
- Given the installed package, When `assets/icon.ico` is looked up with `importlib.resources`, Then the file exists.
- Manual, device-only: `uv tool install .`, then `screen-copier --create-shortcut`, then double-click the icon → the app opens with no console window. Note the result in the PR.

## Target files

## Notes for the worker
`shortcut.py` exposes `create_shortcut() -> int`. Resolve the `screen-copier` executable with `shutil.which` and the icon with `importlib.resources`; then run `powershell -NoProfile -Command` with a `WScript.Shell` `CreateShortcut` script that writes `Screen Copier.lnk` into `[Environment]::GetFolderPath('Desktop')`, which handles OneDrive-redirected Desktops. Print the path and return 0, or print stderr and return 1. pywin32 is banned (AGENTS.md); PowerShell through `subprocess` is the way. Wire the flag into `build_parser()` and `main()` in `app.py` without touching the startup flow T019 wrote. The icon is simple and original.
