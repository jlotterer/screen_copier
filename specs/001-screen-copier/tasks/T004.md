# T004: Settings, API-key resolution, data dir, logging

## Goal
When this task is done, `src/screen_copier/config/` provides settings persistence (`settings.py`), API-key resolution through the environment and keyring (`secrets.py`), data-directory paths (`paths.py`) and a rotating, key-redacting log (`logging.py`), so every later module reads tunables from `Settings` and never handles the key or the data folder itself. Pure Python, no Qt.

## Acceptance criteria
- Given a settings file containing `{"model": "claude-opus-5-5", "bogus": 1}`, When `load_settings` runs, Then `model` is `claude-opus-5-5`, the unknown key is ignored, every other key has its default, and no error is raised.
- Given a settings file that is not valid JSON, When `load_settings` runs, Then the file is renamed to `settings.bak.json` and all defaults are returned.
- Given `ANTHROPIC_API_KEY` set and a different key stored in a fake keyring backend, When `get_api_key` runs, Then the environment value is returned.
- Given no environment variable and a key in the fake keyring, When `get_api_key` runs, Then the keyring value is returned.
- Given neither an environment variable nor a stored key, When `get_api_key` runs, Then `None` is returned.
- Given a fake keyring backend that raises `KeyringError`, When `keyring_available` runs, Then it returns `False`.
- Given logging is set up in a temporary data dir, When the message `key=sk-ant-abc123` is logged, Then the log file contains `sk-ant-***` and does not contain `sk-ant-abc123`.
- Given a key ending in `abcd`, When `mask_key` runs, Then it returns `••••abcd` and nothing else of the key.
- Given the modules under `src/screen_copier/config/`, When their import statements are inspected, Then none imports PySide6.

## Notes for the worker
`paths.py`: `data_dir()` honours `SCREEN_COPIER_DATA_DIR`, else platformdirs; `sessions_dir()` and `logs_dir()` create their folders as needed; `atomic_write_text` is the temp-file-then-replace helper sessions reuse. `settings.py`: a `Settings` pydantic model with every key, type, range and default from the Settings contract; `load_settings()` is tolerant (unknown keys ignored, invalid or out-of-range values fall back to the default per key, unreadable JSON → `settings.bak.json` and defaults); `save_settings()` writes atomically. `secrets.py`: `get_api_key`, `set_api_key`, `clear_api_key`, `keyring_available`, `api_key_from_env` and `mask_key`, with the keyring backend injectable so tests use a fake and never touch Credential Manager. `logging.py`: `setup_logging()` installs the rotating handler (1 MB, 5 backups, INFO) and a filter that replaces `sk-ant-[A-Za-z0-9_-]+` with `sk-ant-***`. Never write the key to any file. Background: [architecture.md §8](../../../docs/architecture.md#8-settings--environment) and [§16](../../../docs/architecture.md#16-errors--logging).
